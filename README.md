# VERIFEX AI — Verify Every Export Before It Ships

AI-powered export document intelligence that detects inconsistencies across shipping paperwork, predicts customs queries, and ensures shipments are compliant before departure.

---

## Overview

International export workflows often suffer from costly delays due to document discrepancies between Invoices, Packing Lists, Shipping Bills, Certificates of Origin, and Bills of Lading. **VERIFEX AI** provides real-time multi-document verification and golden-record cross-referencing:

- **Automated Discrepancy Detection**: Pinpoints HS code mismatches, quantity & weight variations, currency errors, and expiring regulatory certificates.
- **Customs Risk Assessment**: Scores shipments on compliance risk before submission to customs authorities.
- **Golden Record Extraction**: Creates a unified truth across inconsistent shipping documents.
- **Natural Language Assistant**: Query documents and compliance status using AI.

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd "IBM Hackathon"
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:8080`.

---

## Available Scripts

- `npm run dev`: Runs the development server at `http://localhost:8080`
